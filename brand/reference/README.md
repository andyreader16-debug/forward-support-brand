# Reference

Canonical example PDFs of Forward Support documents, matching what is live on forwardsupport.co.uk. Before building any new document, open the closest match here and check your output against it.

## Current (authority)

- `Placement_Pack_v2.pdf`: Placement Information Pack for commissioners. Same file as the live website download.
- `Family_Guide_v2.pdf`: Family Home Guide. Same file as the live website download.
- `Social_Worker_Guide_v2.pdf`: Social Worker Guide. Same file as the live website download.
- `Stationery_Samples.pdf`: letterhead, continuation sheet, memo, compliment slip, business cards, email signature.

## How to use these

Confirm the new output uses the same eyebrow colour (cyan on content pages), the same keyword accent (cyan), the same content chrome, the same footer pattern and the same callout colours. If it looks different in any meaningful way, you are drifting. Stop and reconcile.

When a live document is rebuilt, replace its file here in the same commit, so the reference always matches what people actually receive.
