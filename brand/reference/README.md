# Reference

Canonical example PDFs of Forward Support documents as built and as in customer hands. Anyone building a new document should look at the relevant one here first to verify the new output matches the established visual language.

## In here

- `Placement_Pack_April_2026.pdf` — current Placement Information Pack for commissioners. Definitive example of cover, internal page chrome, callouts, and footer.
- `Family_Guide_April_2026.pdf` — current Family Guide. Same chrome family, warmer tone.
- `Statement_of_Purpose_April_2026_DRAFT.pdf` — current draft Statement of Purpose. Same chrome family, formal tone.
- `Stationery_Samples.pdf` — letterhead, continuation sheet, memo, compliment slip, business cards, email signature as previewed in Brand Book Section 09.

## How to use these

Before producing any new document, open the closest match in here. Confirm the new output uses the same eyebrow colour, the same keyword accent, the same content chrome, the same footer pattern, the same callout colours. If your output looks different in any meaningful way, you are drifting and need to stop and reconcile.
